# Advanced Input Simulator

Advanced Input Simulator 是一款专为 Windows 平台打造的高性能、低延迟、拟真自动化模拟打字与全局按键映射工具。软件支持从慢速教学演示到 6000 字/分（CPM）极限速率的精准时间轴输入，具备自然拟真节奏、代码防多重缩进、换行误发保护、底层物理按键映射、右侧贴边极速悬浮卡片以及智能前台防遮挡激活等工程级特性。

---

## 软件介绍与特性

### 1. 核心定位
本工具主要用于自动化文档录入、代码键入演示、客服快速话术发送、键盘手感打字演练以及防止通讯软件换行误发等场景。通过直接向 Windows 系统底层消息管线投送 UTF-16 Unicode 码流，完全独立于操作系统当前的输入法状态，无论系统处于中文拼音还是英文输入状态，均能保证零乱码、无错漏、高保真地逐字键入。

### 2. 主要特性
- **高精度宽频模拟引擎**：支持 10 至 6000 字/分（CPM）超宽范围无级调速。集成 Windows 多媒体高精度微秒级计时调度，杜绝常规计时器的累计漂移，极速状态下依然保持平滑均匀，不丢字、不跳字。
- **拟真随机节奏**：内建自然微颤算法，智能识别逗号、句号、感叹号、分号及换行等标点符号，模拟真人敲键的微小时间波动与长句停顿，使自动打字效果自然逼真。
- **智能换行保护机制**：支持将换行符自动转为 Shift+Enter 组合键输出，从根本上防止在微信、企业微信、QQ、钉钉、Teams 等通讯软件中换行误触发消息发送。
- **代码编辑器模式**：专为编程演示设计。开启后在换行时自动跳过后续行首的空格与制表符（Tab），与各类主流 IDE（VS Code、Visual Studio、JetBrains 等）的自带自动缩进机制完美契合，杜绝二次重叠缩进导致的排版错乱。
- **全局按键映射与退格撤销**：
  - 将预设文本装载为按键映射序列，用户敲击物理键盘的任意字符按键均会强行拦截原物理键，严格按照预设文本顺序输出下一个字符；
  - 完整支持物理退格键（Backspace）擦除撤销机制，按下退格键时自动擦除目标软件中已输入的字符并精准回退文本序列指针。
- **屏幕贴边微型悬浮卡片**：
  - 主窗口最小化时无缝转换为屏幕右侧边缘的高清贴边图标，无闪烁平滑过渡；
  - 鼠标移动至悬浮图标自动滑出极速输入卡片，支持剪贴板一键粘贴、一键清空与“立即打字”；
  - 智能前台焦点交接机制：触发打字时自动将键盘焦点瞬态交接回上一个目标应用程序；
  - 鼠标移开悬浮区域并在任意外部位置单击时，卡片自动静默收起。
- **独立急停拦截与全局热键**：
  - Ctrl+Alt+T：全局打字启动与暂停切换；
  - Esc：打字过程中专属急停按键。采用底层低级键盘钩子，仅在打字进行中触发急停并彻底拦截吃掉该按键，不穿透至前台工作软件；未打字状态下完全放行，不影响系统和其他软件的正常 Esc 操作；
  - F10：按键映射功能全局开关。按下即可实时切换映射状态，主界面复选框与悬浮图标右键菜单实现百分之百双向实时同步；
  - Ctrl+F12：重置程序状态；
  - F11：完全禁用按键映射。
- **前台焦点穿透与防遮挡机制**：
  - 针对 Windows 系统的 UAC 特权隔离和前台锁定策略（Foreground Lockout），内置瞬态层级提升与窗口管理技术，确保程序启动或从悬浮图标还原时，主窗口直接浮升至屏幕最前台并获取焦点，绝不被浏览器、文件管理器或其它窗口遮挡。

## 安装与运行环境

### 1. 系统要求
- **操作系统**：Windows 7 / Windows 8 / Windows 8.1 / Windows 10 / Windows 11（支持 x86 与 x64 架构）。
- **运行环境**：.NET Framework 4.8 或更高版本（Windows 10 1903 及以上版本、Windows 11 已默认内置，无需额外部署）。

### 2. 部署与权限说明
- **便携免安装**：本软件为绿色单文件应用程序（`Advanced Input Simulator.exe`），无需安装、不写注册表常驻服务，解压后放置于任意目录均可直接双击运行。
- **管理员权限要求**：程序内建 `requireAdministrator` 运行清单。由于需要安装系统级全局底层键盘钩子（`WH_KEYBOARD_LL`）以实现物理按键强行拦截与跨窗口打字急停，软件启动时需要以管理员权限运行。若无管理员权限，当目标输入窗口处于高权限时（如任务管理器、管理员命令提示符、部分专业开发工具），Windows UIPI 机制将禁止消息注入与按键捕获。

## 详细使用指南

### 1. 基础模拟打字操作
1. **输入准备**：双击启动 `Advanced Input Simulator.exe`，在主界面左侧“输入/待打字文本”多行编辑框中输入或粘贴待打字内容；也可直接点击右上方的“粘贴剪贴板”按钮自动规整换行并载入。
2. **参数配置**：
   - **速度调节**：在右侧“模拟打字设置”中拖动“打字速度”滑块调节速率，或直接点击预设按钮（`150慢速`、`400日常`、`800快速`、`2400急速`、`6000极限`）；
   - **节奏控制**：按需勾选“启用拟真随机节奏”；
   - **输出防护**：若用于社交聊天工具，勾选“换行使用 Shift+Enter”；若用于编写代码，勾选“代码编辑器模式”；
   - **启动等待**：默认等待时间为 0 秒。如需给手动切换窗口预留缓冲时间，可调节“启动等待”滑块（0–60秒）。
3. **开始打字**：
   - 方式 A：点击主界面的“开始打字”按钮；
   - 方式 B：将输入焦点切换到目标软件的文本框后，直接按下全局快捷键 `Ctrl+Alt+T`，程序立即开始自动录入。
4. **中断与恢复**：
   - 打字进行中，可随时按下物理键盘的 `Esc` 键或组合键 `Ctrl+Alt+T`，输入立即停止，且目标软件中不会留下任何多余按键输入；
   - 点击“暂停”/“继续”可按当前字符位置进行进度恢复。

### 2. 全局按键映射模式（盲打演练 / 逐键序列输入）
1. 在左侧文本框内装载待输入的源文本。
2. 勾选“启用按键映射功能 (拦截物理键并按文本顺序输出)”（默认开启）。
3. 切换到目标软件（如记事本、IDE 或聊天窗口）的输入焦点处。
4. 此时在键盘上任意敲击字母、数字或符号键，程序将拦截原本的物理按键，严格按照文本源文件的字符顺序逐个吐字输出。
5. 若出现输入偏差需要回退，直接按下物理键盘上的 `Backspace`（退格键），程序将执行真实擦除撤销并自动回退内部字符指针。
6. 随时按下全局快捷键 `F10`，即可瞬间开启或关闭映射功能，主界面复选框会同步变换勾选状态。

### 3. 右侧贴边悬浮卡片操作
1. **进入悬浮模式**：点击主界面右上角的最小化按钮，主界面平滑隐匿，屏幕右侧边缘出现吸附式高清悬浮图标。
2. **唤出快速卡片**：将鼠标指针悬停至悬浮图标上方，图标左侧会自动平滑滑出“快速粘贴打字”面板。
3. **快速录入与开始**：
   - 点击“粘贴剪贴板”直接抓取剪贴板最新文本，或点击“清空”重置卡片；
   - 点击“立即打字”或在卡片激活状态下按下 `Ctrl+Alt+T`，系统自动将前台焦点切换回目标工作软件，并在稳定后立即执行流式模拟打字；
   - 若要放弃当前快速卡片，将鼠标移开并在屏幕任意其他窗口或空白处单击一下，卡片自动隐藏。
4. **悬浮图标右键菜单**：在右侧悬浮图标上点击鼠标右键，可呼出便捷上下文菜单，直接切换“启用按键映射功能”、“换行使用 Shift+Enter”、“代码编辑器模式”或执行“退出程序”。
5. **恢复主界面**：直接使用鼠标左键单击悬浮图标，主界面将自动浮升至所有窗口最前台并激活，悬浮图标同步隐藏。

## 全局快捷键一览

| 功能名称 | 默认快捷键 | 生效时机与行为说明 |
| :--- | :--- | :--- |
| **打字功能切换** | `Ctrl+Alt+T` | 全局生效。未打字时开始打字；打字进行中时暂停/停止打字。 |
| **紧急停止打字** | `Esc` | 仅在打字进行中拦截并生效。即刻中断输出，不向目标前台软件发送 Esc。 |
| **映射功能切换** | `F10` | 全局生效。一键开启或关闭按键映射，主界面与悬浮菜单同步响应。 |
| **重置程序状态** | `Ctrl+F12` | 全局生效。紧急停止所有打字任务并重置映射与进度状态至就绪。 |
| **映射完全禁用** | `F11` | 全局生效。强制取消勾选按键映射功能并解除所有键盘拦截。 |

## 常见问题解答 (FAQ)

#### Q1: 为什么程序启动时 Windows 会弹出用户账户控制（UAC）提示？
软件实现物理按键映射与跨窗口模拟打字依赖于底层的 Win32 消息挂钩技术（`SetWindowsHookEx`）。若目标软件是以管理员权限运行的进程（例如 Visual Studio、管理员终端或任务管理器），根据 Windows 系统的特权隔离（UIPI）安全策略，普通权限应用无法向高权限应用发送按键消息。以管理员身份运行可确保本工具能对系统内的所有目标窗口均正常工作。

#### Q2: 为什么模拟输入汉字时，即使当前开启了搜狗、微软拼音等输入法也不会出现拼音候选框？
本程序采用 Win32 `SendInput` 的 Unicode 虚拟扫描通道（`KEYEVENTF_UNICODE`）直接向系统的输入队列注入 UTF-16 字符。该机制绕过了系统输入法（IME）的前置拼音解析流程，因此即便用户在输入法开启状态下模拟打字，也不会出现任何候选框打断，保障了高频输入的绝对稳定。

#### Q3: 为什么在按键映射模式下，按某些快捷键（如 Ctrl+C、Ctrl+V、Tab）没有被拦截？
按键映射模式内建了控制键与功能键白名单机制。所有带有 `Ctrl`、`Alt`、`Win` 等系统控制修饰键的快捷键组合，以及 `F1–F24` 功能键、方向键、翻页键等均被直接放行，以确保用户在进行映射打字的同时，依然能够自由进行复制、粘贴、光标移动和系统导航。

#### Q4: 提示部分快捷键注册失败如何解决？
如果本地其他软件（如显卡驱动控制面板、截图工具或音乐播放器）占用了 `F10` 或 `Ctrl+Alt+T`，程序会在启动时尝试自动降级为备用组合键（如 `Ctrl+F10`）。用户可以随时点击主界面顶部的“快捷键说明”按钮，查看当前当前系统实际成功注册的生效按键。

#### Q5: 程序的运行日志存放在哪里？
软件的运行日志与诊断信息存放于系统本地数据目录中：`%LOCALAPPDATA%\AdvancedInputSimulator\Logs`。若遇到任何异常运行状况，可查阅该目录下的最新日志文件获取详细的堆栈跟踪信息。
